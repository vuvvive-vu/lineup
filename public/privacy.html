1. Что мы собираем

Togetherly собирает только минимально необходимые данные для работы сервиса:

  • Имя пользователя (ник) - отображаемое имя, которое вы указываете при входе.
  • Электронная почта - используется только для регистрации через почту, подтверждения и восстановления доступа. Для быстрого входа не требуется.
  • Пароль - хранится только в виде хеша, мы не видим ваш исходный пароль.
  • Аватар - эмодзи или загруженное фото (сжатое до 256px, не более ~500 КБ).
  • Биография - произвольный текст до 120 символов.
  • Сообщения чата - текстовые сообщения до 500 символов. Хранятся в активных комнатах (до 200 сообщений) и удаляются при выходе всех участников.
  • Реакции - эмодзи-реакции на сообщения.

2. Как мы используем данные

  • Имя пользователя, аватар и био отображаются другим участникам в профиле и списке участников комнаты.
  • Адрес почты используется только для отправки кода подтверждения и кода для сброса пароля.
  • Сообщения чата видны всем участникам комнаты в реальном времени.
  • Мы не используем ваши данные для таргетированной рекламы, аналитики или продажи третьим сторонам.

3. Хранение данных

  • Аккаунты, созданные через почту, хранятся в базе данных PostgreSQL (Supabase) на постоянной основе и не удаляются при выходе из аккаунта.
  • Гостевые аккаунты (быстрый вход) являются временными и хранятся только в памяти сервера.
  • Сообщения чата хранятся на сервере и удаляются при опустошении комнаты.
  • Токены авторизации хранятся только в браузере (localStorage) в виде JWT.

4. Третьи стороны

Togetherly использует следующие сервисы:

  • Resend / Amazon SES - для отправки писем с кодами подтверждения.
  • YouTube - YouTube IFrame API для воспроизведения видео.
  • VK - VK Video API для воспроизведения видео.
  • Rutube - встраивание видео через iframe.

Видео-сервисы могут собирать данные в соответствии с собственными политиками конфиденциальности. Мы не несём ответственности за их практики.

5. Безопасность

Мы принимаем разумные меры для защиты ваших данных:

  • Данные передаются по протоколу HTTPS.
  • Пароли хранятся только в виде хеша.
  • Доступ к базе данных ограничен серверным окружением.
  • Действуют лимиты на отправку кодов для защиты от спама.

Для защиты вашего аккаунта используйте надёжный пароль и не передавайте коды из писем третьим лицам.

6. ваши права

  • Право на редактирование - вы можете изменить ник, аватар и био в любое время через настройки профиля.
  • Право на удаление - вы можете запросить удаление своего аккаунта, обратившись по адресу support@togetherly.online.
  • Право на доступ - вы можете запросить информацию о сохранённых данных по тому же адресу.

7. Контакты

По всем вопросам обращайтесь: support@togetherly.online.

1. What We Collect

Togetherly collects only the minimum data necessary to operate the service:

  • Username - a display name You choose when signing in.
  • Email - used only for email registration, verification and password recovery. Not required for quick login.
  • Password - stored only as a hash, we never see Your original password.
  • Avatar - either a preset emoji or an uploaded photo (compressed to 256px, max ~500 KB).
  • Bio - free-text up to 120 characters.
  • Chat messages - plain text up to 500 characters. Stored in active rooms (up to 200 messages) and deleted when all participants leave.
  • Reactions - emoji reactions on messages.

2. How We Use Data

  • Your username, avatar, and bio are displayed to other users in Your profile and room participant lists.
  • Your email is used only to send a verification code and a password reset code.
  • Chat messages are visible to all room participants in real time.
  • We do not use data for targeted advertising, analytics, or selling to third parties.

3. Data Storage

  • Email accounts are stored in a PostgreSQL database (Supabase) permanently and are not deleted when You sign out.
  • Guest accounts (quick login) are temporary and stored only in server memory.
  • Chat messages are stored on the server and deleted when a room becomes empty.
  • Auth tokens are stored only in Your browser (localStorage) as a JWT.

4. Third-Party Services

Togetherly uses the following services:

  • Resend / Amazon SES - to send verification emails.
  • YouTube - YouTube IFrame API for video playback.
  • VK - VK Video API for video playback.
  • Rutube - video embedding via iframe.

These services may collect data in accordance with their own privacy policies. We are not responsible for their data collection practices.

5. Security

We take reasonable measures to protect Your data:

  • Data is transmitted over HTTPS.
  • Passwords are stored only as hashes.
  • Database access is restricted to the server environment.
  • Limits apply to code sending to protect against spam.

Please use a strong password and do not share codes from emails with third parties.

6. Your Rights

  • Right to edit - You can change Your username, avatar, and bio at any time through profile settings.
  • Right to delete - You can request deletion of Your account at support@togetherly.online.
  • Right to access - You can request information about stored data at the same address.

7. Contact

For privacy inquiries, contact us at: support@togetherly.online.
