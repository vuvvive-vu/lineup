1. Что мы собираем

Togetherly собирает только минимально необходимые данные для работы сервиса:

  • Имя пользователя (ник) — отображаемое имя, указываемое при входе. Не является уникальным идентификатором аккаунта.
  • Аватар — эмодзи или загруженное фото (преобразованное в base64, сжатое до 256px, не более ~500 КБ).
  • Биография — произвольный текст до 120 символов.
  • Сообщения чата — текстовые сообщения до 500 символов. Хранятся в активных комнатах (до 200 сообщений) и удаляются при выходе всех участников.
  • Реакции — эмодзи-реакции на сообщения (до 4 символов).

Важно: каждый вход в сервис создаёт новый временный аккаунт. При выходе из аккаунта все данные (ник, аватар, био) автоматически удаляются из базы данных.

2. Как мы используем данные

  • Имя пользователя, аватар и био отображаются другим участникам в профиле и списке участников комнаты.
  • Сообщения чата видны всем участникам комнаты в реальном времени.
  • Мы не используем данные для таргетированной рекламы, аналитики или продажи третьим сторонам.
  • Мы не собираем адреса электронной почты, номера телефонов или любую другую личную идентифицирующую информацию.

3. Хранение данных

  • Аккаунты хранятся в базе данных PostgreSQL на серверах Render.com (США) и автоматически удаляются при выходе из аккаунта.
  • Сообщения чата хранятся локально на сервере в файле и удаляются при опустошении комнаты.
  • Токены авторизации хранятся только в браузере пользователя (localStorage) и не передаются на сервер в зашифрованном виде.
  • Данные не дублируются и не передаются в сторонние хранилища.

4. Третьи стороны

Togetherly загружает скрипты следующих сервисов исключительно для воспроизведения видео:

  • YouTube — YouTube IFrame API для воспроизведения видео.
  • VK — VK Video Player API для воспроизведения видео.
  • Rutube — встраивание видео через iframe.

Эти сервисы могут собирать данные в соответствии с собственными политиками конфиденциальности. Мы не несём ответственности за их практики сбора данных.

5. Безопасность

Мы принимаем разумные меры для защиты ваших данных:

  • Данные передаются по протоколу HTTPS.
  • Доступ к базе данных ограничен серверным окружением.
  • Админ-панель защищена паролем.

Авторизация в Togetherly работает по имени пользователя без пароля. Каждый вход создаёт новый временный аккаунт, который автоматически удаляется при выходе. Ник не является уникальным — несколько пользователей могут использовать один и тот же ник одновременно.

6. Ваши права

  • Автоматическое удаление — ваш аккаунт автоматически удаляется из базы данных при выходе из аккаунта.
  • Право на редактирование — вы можете изменить ник, аватар и био в любое время через настройки профиля.
  • Право на доступ — вы можете запросить информацию о сохранённых данных по адресу support@togetherly.online.

7. Контакты

По всем вопросам обращайтесь: support@togetherly.online.

1. What We Collect

Togetherly collects only the minimum data necessary to operate the service:

  • Username — a display name you choose when logging in. It is not a unique account identifier.
  • Avatar — either a preset emoji or an uploaded photo (converted to base64, compressed to 256px, max ~500 KB).
  • Bio — free-text up to 120 characters.
  • Chat messages — plain text up to 500 characters. Stored in active rooms (up to 200 messages) and deleted when all participants leave.
  • Reactions — emoji reactions on messages (up to 4 characters).

Important: each login creates a new temporary account. When you log out, all your data (username, avatar, bio) is automatically deleted from the database.

2. How We Use Data

  • Your username, avatar, and bio are displayed to other users in your profile and room participant lists.
  • Chat messages are visible to all room participants in real time.
  • We do not use data for targeted advertising, analytics, or selling to third parties.
  • We do not collect email addresses, phone numbers, or any other personally identifiable information.

3. Data Storage

  • Accounts are stored in a PostgreSQL database on Render.com servers (USA) and automatically deleted when you log out.
  • Chat messages are stored locally on the server in a file and deleted when a room becomes empty.
  • Auth tokens are stored only in the user's browser (localStorage) and are not sent to the server in encrypted form.
  • Data is not duplicated or transferred to third-party storage.

4. Third-Party Services

Togetherly loads scripts from the following services solely for video playback:

  • YouTube — YouTube IFrame API for video playback.
  • VK — VK Video Player API for video playback.
  • Rutube — video embedding via iframe.

These services may collect data in accordance with their own privacy policies. We are not responsible for their data collection practices.

5. Security

We take reasonable measures to protect your data:

  • Data is transmitted over HTTPS.
  • Database access is restricted to the server environment.
  • The admin panel is password-protected.

Togetherly authentication works by username without a password. Each login creates a new temporary account that is automatically deleted when you log out. Usernames are not unique — multiple users can use the same username simultaneously.

6. Your Rights

  • Automatic deletion — your account is automatically deleted from the database when you log out.
  • Right to edit — you can change your username, avatar, and bio at any time through profile settings.
  • Right to access — you can request information about stored data at support@togetherly.online.

7. Contact

For privacy inquiries, contact us at: support@togetherly.online.
